**Issue comment format (mandatory for fixers):**
- Start every `add_comment` body with the heading `## Issue Fixer` (exactly that title; nothing else on that line).
- Place the heading before the `tl;dr` / recommendation sections.
- Keep **Related Items** compact: put them in a `<details>` block and use grouped bullets (Issues / PRs / Files / Links), not a Type|Reference|Relevance table.
